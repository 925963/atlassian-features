## Description

Organization admins can now add Jira Product Discovery to new or existing sites directly from Atlassian Administration — no need to contact support. Start a trial or add Jira Product Discovery to more sites on your Enterprise plan in just a few steps. Log in to admin.atlassian.com and select your organization.
	Go to Apps, then select Atlassian apps.
	Select Add app, then select Jira Product Discovery.
	Pick an existing site or create a new one.
