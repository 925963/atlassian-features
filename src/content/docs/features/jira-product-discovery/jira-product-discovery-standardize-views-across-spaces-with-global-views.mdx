## Description

Jira admins can now create and manage global views to standardize configurations across multiple Jira Product Discovery spaces. This helps teams enforce processes at scale and ensures a consistent experience by providing pre-configured views that can be automatically added to new spaces. To get started with this change: Go to Settings (the cog icon) in the top navigation bar.
	Under Jira admin settings, select Jira apps, then choose Jira Product Discovery from the sidebar.
