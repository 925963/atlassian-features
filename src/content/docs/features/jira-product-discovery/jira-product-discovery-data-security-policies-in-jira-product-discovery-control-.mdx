## Description

Jira Product Discovery now supports Atlassian Guard data security policies, giving organization admins more control over how project data is shared and accessed. This update helps ensure your organization remains compliant by allowing admins to restrict data exports, attachment downloads, and the creation of public links for your discovery projects. Share discovery project views To get started with this change Go to Atlassian Administration, then select Security.
