## Description

App admins of Atlassian organizations that have only Jira apps can now activate Jira Service Management and Jira Product Discovery directly from the template picker. This simplifies the setup by combining app activation and project creation into a single step, helping you start using new features faster. To view this change: Open the Jira template picker.
	Select a Jira Service Management or Jira Product Discovery template.
	Review the template preview and app overview on the new setup page.
