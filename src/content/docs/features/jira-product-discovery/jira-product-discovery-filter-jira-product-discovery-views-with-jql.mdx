## Description

Save time by using Jira Query Language (JQL) to create precise, complex filters for your ideas. Jira Product Discovery now supports advanced filtering, allowing you to build views based on specific criteria like "current user," reporter, or complex OR/NOT logic. To use JQL for filtering views: Open a Jira Product Discovery view.
	Select the Filter button in the view header.
	In the Ideas section of the sidebar, select Add filter.
	Select the JQL filter option.
	Enter your query in the JQL editor
