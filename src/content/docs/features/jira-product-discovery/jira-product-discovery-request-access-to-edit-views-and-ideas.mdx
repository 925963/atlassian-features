## Description

Jira Product Discovery users can now request edit permissions directly from the view header. This change allows people with view-only access to easily ask for the permissions they need to contribute to ideas and manage views, reducing friction and helping teams collaborate more effectively. Open a space in Jira Product Discovery where you have view-only access.
	Select Request access in the view header.
	Wait for an admin to review and approve your request.
