## Description

Immutable tags for the Bitbucket Packages container registry help workspace admins control whether container image tags can be changed after they are first pushed. You can leave tags mutable, protect every tag in the workspace, or protect only tags that match custom rules. This helps teams improve reproducibility, reduce deployment risk, and support compliance requirements for container images.
