## Description

Bitbucket Pipelines now supports flaky test remediation using agentic pipelines. This feature in Bitbucket Cloud allows you to automatically diagnose and repair flaky tests with a single action, helping you maintain a reliable CI/CD process and reduce false build failures. To get started with this change: Go to Workspace settings and ensure Agentic pipelines is enabled.
