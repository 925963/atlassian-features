## Description

Internal packages let repository admins make a package readable by every member of a Bitbucket Cloud workspace, without giving them access to the linked repository. Use internal packages to share common packages across a workspace without needing to open the source repository to consumers. Internal packages are read-only for workspace members who don’t have repository access. They can browse, pull, download and install the package, but can’t push, delete or manage it.
