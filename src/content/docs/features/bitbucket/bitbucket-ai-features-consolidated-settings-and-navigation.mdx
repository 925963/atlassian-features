## Description

We've simplified how you manage AI in Bitbucket Cloud by consolidating all related settings into a single AI menu. This update renames Atlassian Intelligence to AI features and moves Agentic pipelines and Rovo Dev into this new workspace settings location. These changes make it easier for admins to discover, enable, and manage AI capabilities across their workspace from one central place. Go to your Bitbucket workspace and select Workspace settings.
	Select the new AI menu in the sidebar.
