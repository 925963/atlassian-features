## Description

Bitbucket Cloud now includes test management dashboards to help you track and analyze your test results. This change provides a centralized view of your testing data, allowing you to identify trends and improve software quality. Log in to your Bitbucket Cloud workspace.
	Navigate to the repository where you want to view test results.
	Select Tests from the sidebar to open the test management dashboard.
