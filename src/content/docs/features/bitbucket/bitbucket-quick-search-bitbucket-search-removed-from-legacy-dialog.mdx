## Description

To improve the performance and reliability of search across Atlassian apps, we've removed the Bitbucket search tab from the legacy Quick Search dialog in all apps except Bitbucket. This change helps us streamline the search experience and focus on more modern search capabilities. You can still search for Bitbucket repositories directly within Bitbucket. Open the search dialog in any Atlassian app other than Bitbucket.
