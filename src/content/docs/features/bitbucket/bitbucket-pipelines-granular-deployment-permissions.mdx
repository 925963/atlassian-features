## Description

Bitbucket Cloud is introducing granular deployment permissions for deployment environments in Bitbucket Pipelines. Repository admins can now control exactly which individual users and workspace groups are allowed to deploy to each environment, helping teams protect sensitive environments like Production while allowing authorized non-admin users to trigger deployments. To get started with this change Go to Repository settings, then Deployments.
