## Description

Bitbucket Cloud now gives you two new actions to manage your test results without leaving your workflow. You can create Jira work items directly from a test to quickly capture and track bugs or tasks identified during testing, and you can remove individual tests to clean up stale or one-time errored tests that clutter your Tests view and skew your test health metrics.
