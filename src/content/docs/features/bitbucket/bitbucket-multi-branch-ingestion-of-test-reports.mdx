## Description

Branch tracking allows teams to configure which branches Bitbucket Tests collects results from. It has the following two parts: Default branch - Test results are always collected. This is your Git default branch, for example 'main', but can be pointed to any other branch you may want to track. There can only be one default branch. Additional branches - You can also add up to four more branches that you choose from a dropdown menu, so you can track the test results of a total of 5 branches.
