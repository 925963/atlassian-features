## Description

Instead of having to continue to rely only on global options, we are introducing a new flexible way to supply step options called 'step-config'. Now, you can simply define a named step config under you can simply define a named step config under step-config within your definitions and reference it within the config for that step. This will supply all options from the defined step config as default options.
