## Description

Bitbucket Cloud now supports test ingestion from up to 5 branches per repository. This change allows you to monitor test results across multiple development streams, rather than being limited to the default branch. By marking a specific branch as the default for test ingestion, you can ensure your primary test data is always prioritized while still capturing results from other critical branches. To get started with this change Go to your repository in Bitbucket Cloud.
	Select Repository settings
