## Description

Save time and simplify your cloud-to-cloud migration by importing data into Assets Data Manager directly from files. This new capability allows organization admins to move data between cloud sites using flat files, providing more flexibility and control during the migration process. By using file-based imports, you can ensure your service projects are set up correctly in your new cloud environment without manual data entry. Go to Assets Data Manager and select once of you flat file data sources
