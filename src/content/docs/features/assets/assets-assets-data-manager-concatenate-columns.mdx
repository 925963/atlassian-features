## Description

Modify your imported data in Jira Service Management by combining values from two columns into one. This new transform function in Assets Data Manager helps you build composite keys or more meaningful labels using a transform function. To get started with this change: Go to your service project and select Assets.
	Select Data Manager, then choose the import you want to edit.
