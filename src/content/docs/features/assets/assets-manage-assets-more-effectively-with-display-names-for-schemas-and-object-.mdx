## Description

Manage your assets more effectively in Jira Service Management with the introduction of display names for asset entities. You can now set a user-facing Display name for schemas, object types, and attributes, which is separate from the system Name used in APIs and scripts. This change allows you to use human-friendly labels in the UI while maintaining stable, developer-friendly identifiers for integrations. To set a display name: Go to Assets in your Jira Service Management project.
