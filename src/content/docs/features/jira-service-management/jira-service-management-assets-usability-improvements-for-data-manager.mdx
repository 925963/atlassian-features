## Description

We’ve made several usability improvements to the Assets Data Manager admin journey in Jira Service Management. These changes refine the experience for admins following the recent release of the new Data Manager journey, making it easier to manage your data. To get started with this change Go to your service project.
	Select Assets from the navigation on the left.
	Select Data Manager to view the updated admin journey.
