## Description

Confluence administrators can now turn off built-in space and content access requests. This allows you to route users to your organization's established access request systems, such as Jira Service Management, ensuring a consistent audit trail and reducing administrative burden. To turn off access requests and set up custom messaging: Go to Confluence administration.
