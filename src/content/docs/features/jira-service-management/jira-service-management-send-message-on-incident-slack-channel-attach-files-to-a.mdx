## Description

You can now attach up to 10 files (totaling 4MB) to messages sent using the "Send message on incident Slack channel" automation action in Jira Service Management. This helps responders access runbooks, checklists, and supporting materials directly in Slack, reducing context switching and speeding up incident response. Go to Project settings in Jira Service Management.
