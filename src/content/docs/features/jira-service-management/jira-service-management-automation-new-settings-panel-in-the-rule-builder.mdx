## Description

We’ve moved several configuration options in the automation rule builder to a dedicated settings panel. This change helps you manage your automation rules more effectively.. To get started with this change: Open an existing automation rule or create a new one.
	Select the More menu (represented by three dots) in the rule builder.
	Select Settings to open the new panel and manage your rule configuration.
