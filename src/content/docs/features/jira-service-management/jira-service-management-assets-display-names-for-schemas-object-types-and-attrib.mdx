## Description

Manage your data more intuitively in Jira Service Management by adding display names to Assets entities. You can now clearly label and recognize schemas, object types, and attributes at a glance, removing the need to guess when identifying specific data structures. To get started with this change Open the Assets app.
	Select the schema, object type, or attribute you want to update.
