## Description

We’re introducing limits and guardrails for work item types and fields to improve site performance and scalability. You’ll see a warning if a space exceeds 700 fields or 150 work item types. To keep your site running smoothly, you won't be able to add more until the space is back within these limits. Understand data limits and guardrails To get started with this change:
