## Description

We’ve updated the admin experience for Assets Data Manager in Jira Service Management to make setting up and managing your data sources easier, faster, and more intuitive. This new Data Manager admin experience ensures a consistent look and feel with the Atlassian apps you already use. We’ve also updated several key terms to be more descriptive of their function, helping you navigate your asset data with less friction.
