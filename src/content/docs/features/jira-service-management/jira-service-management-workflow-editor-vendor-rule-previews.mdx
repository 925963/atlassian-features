## Description

You can now view configuration summaries for vendor rules directly from rule cards in the workflow editor. This update allows you to quickly understand how a rule is set up without needing to open the edit screen. Edit a workflow in the new workflow editor.
	Select a transition to view its configured rules.
	Select Preview to view the rule summary in a popup.
