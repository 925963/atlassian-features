## Description

We’re building new navigation components for Dashboards and Data Manager within Assets for customers on Standard plans. These components are designed to lead you to a premium discovery page where you can learn about advanced data management and reporting tools before deciding to start a trial. To interact with these new Assets components: Click the new Dashboards or Data Manager components.
	Review the information on the discovery page to see how these premium features work.
