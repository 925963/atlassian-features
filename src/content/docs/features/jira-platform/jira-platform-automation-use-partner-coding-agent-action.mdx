## Description

Save time and streamline your development workflow by using Jira automation to trigger actions in third-party coding agents. You can now use the partner coding agent action to automate code reviews, documentation updates, or work item analysis directly from Jira. Go to your Jira space and select Space settings, then Automation.
	Select Create flow and choose a trigger for your automation.
	Select New action, then search for and select partner coding agent-*
