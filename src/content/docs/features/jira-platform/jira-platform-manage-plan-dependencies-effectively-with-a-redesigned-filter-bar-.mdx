## Description

Use the redesigned dependency report filter bar in Jira Plans, with improved accessibility and usability. The standard dataset filters now live in a dedicated popup with a responsive layout. All controls remain visible and operable even at 200% browser zoom, enabling you to manage your plan dependencies more effectively across different screen sizes and zoom levels. To get started: Open your plan in Jira and select the Dependency report tab.
