## Description

Save time by discovering and assigning Rovo agents to your work items more easily. Jira now displays an empty state in the agent section when no agents are assigned, making it clear that you can use agents to help progress your work. To get started with this change Open a work item in Jira.
	Locate the Agents section in the work item details.
	If no agents are assigned, you'll see the new empty state.
	Select the agent picker to browse and assign a Rovo agent to your work item.
