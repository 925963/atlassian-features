## Description

Jira Cloud admins now see a pre-enforcement banner on configuration pages for field options, issue security levels, grants per permission and priorities. The banner gives advance notice before limits are enforced, so admins can plan cleanup and optimization ahead of time. To get started with this change: Go to Settings in Jira Cloud.
