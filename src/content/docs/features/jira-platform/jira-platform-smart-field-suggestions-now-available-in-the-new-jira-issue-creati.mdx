## Description

Speed up your workflow and reduce manual data entry with intelligent field suggestions in Jira's modernized work item creation dialog. By analyzing your project's historical patterns and similar issues, Jira now surfaces the most relevant values for both standard and custom fields, helping you capture work faster and with greater accuracy. To get started with this change Smart field suggestions are available for Jira Cloud Standard and Premium plans.
