## Description

Jira Cloud admins can now access streamlining tools from the field schemes experience in Jira admin settings. These tools optimize field schemes by removing unused fields, creating project-specific schemes, splitting schemes, and provide functionality to download optimization details. To get started with this change: From the top navigation, go to Settings, then Work items.
	Select Field schemes.
	Select the field scheme you want to manage.
	Under Actions, select Optimize to use the streamlining
