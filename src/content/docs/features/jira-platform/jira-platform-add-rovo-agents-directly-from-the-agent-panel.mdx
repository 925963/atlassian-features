## Description

Save time when managing work by adding Rovo agents directly from the Agent panel in Jira. You can now access the agent picker and add additional agents to a work item from the panel while other agents are already running. To get started with this change: Open a work item in Jira.
	Locate the Agents section.
	If agents are already working on the work item, you will see an Add agent button (+ icon) located in the top-right corner of the Agents section.
