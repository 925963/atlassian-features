## Description

A new search filter in your space’s Capacity tab lets you search by keyword or key to quickly find work item you need. The search works in both the Work and People views. Capacity planning is a Jira Premium and Enterprise feature. Turn it on using these instructions. Go to the Capacity tab.
	Select the search input field above the list of issues.
	Enter your search terms to filter the results. The search works for keywords and for issue keys.
