## Description

Get a larger view of your work items without leaving the List and Global Search views. Open your List or Global Search view in Jira.
	Select a work item to open it in the modal or preview panel (your preference from other Jira views will be the default method).
	If you’re using the preview panel, select the expand button to open the work item in a modal.
	Use the navigation arrows within the dialog or keyboard shortcuts to move to the next or previous work item in your list.
