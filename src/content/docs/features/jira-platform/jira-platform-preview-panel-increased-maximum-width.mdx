## Description

We've increased the maximum width of the preview panel for Jira’s list to help you view more fields and content without having to open the work item in a modal or new tab. This change allows for faster triage and editing while maintaining the context of your list. In Jira, go to the list view.
	Select a work item from the list to open the preview panel.
	Drag the edge of the preview panel to expand it to the new maximum width.
