## Description

Forge JQL functions in Jira can now run for longer before timing out. We’ve increased the execution timeout from 25 seconds to 55 seconds, allowing your custom functions more time to complete complex searches and data processing. Open your Jira app.
	Go to the search bar and select Advanced issue search.
	Enter a JQL query that uses a Forge-powered function.
	Run the search to see the improved performance for long-running functions.
