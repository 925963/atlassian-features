## Description

Save time and streamline your development workflows by integrating Cursor with automation in Jira. This new action allows you to trigger Cursor tasks directly from your automation rules, helping your team stay focused and productive. To get started with this change Go to Project settings, then Automation.
	Select Create rule or edit an existing rule.
	Add a new action and search for Cursor.
	Configure the action details and select Save.
