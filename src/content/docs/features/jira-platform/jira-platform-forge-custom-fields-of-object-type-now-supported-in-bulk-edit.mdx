## Description

This update enhances the Jira Issue bulk-edit experience for Object type Forge Custom Fields. it replaces the existing TextField input field with a forge-app-defined custom edit experience for Object Forge Custom Field. Note: The Forge app developer has to enable the custom edit experience for bulk edit by adding "issue-bulk-edit" in the manifest. We will fallback to default TextField experience if the Forge app developer doesn’t enable it. Select the work items you want to update from the List
