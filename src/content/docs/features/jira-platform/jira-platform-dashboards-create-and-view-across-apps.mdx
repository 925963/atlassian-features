## Description

Create actionable, visually flexible dashboards in minutes right within Jira. Powered by the Atlassian platform, you can now build custom charts using pre-built templates, interactive dashboard filters, and Rovo-assisted creation, giving your team a unified view of work without complex setup. Go to Dashboards in the navigation bar of your Atlassian app.
	Select Create dashboard.
	Choose to create your dashboard using the new dashboarding capabilities.
	View your new dashboard in Jira.
