## Description

Jira users can now assign an AI agent to multiple work items at once using the bulk actions toolbar. This improvement saves time by allowing you to start sessions for up to 50 work items in a single operation across the List, Global Search, Backlog, and Timeline views. To get started with this change Select up to 50 work items in a supported Jira view, such as the List, Global Search, Backlog, or Timeline.
