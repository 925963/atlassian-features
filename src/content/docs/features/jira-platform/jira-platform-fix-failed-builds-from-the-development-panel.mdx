## Description

Software projects in Jira now include a button in the development panel that allows you to fix failed builds using agents. This update helps you quickly address build issues directly from the work item, saving time and streamlining your development workflow. Open a Jira work item that has a failed build associated with it.
	Locate the development panel in the work item.
	Select the button to fix the build using an agent.
