## Description

Jira is introducing a refreshed work item experience that provides a clearer layout and more prominent core actions. This update simplifies common tasks and helps you focus on the information that matters most without changing your underlying data or integrations. Admins can enable the new work item view for their site. To enable the new work item experience for your site: In Jira, select Settings in the top navigation.
