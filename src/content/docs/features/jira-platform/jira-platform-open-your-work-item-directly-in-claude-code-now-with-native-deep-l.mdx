## Description

Jira Cloud now supports native deep linking for Claude from the status button in the work item view. This update improves the transition between Jira and Claude by using supported deep links, replacing the previous command line interface method. Open a work item in Jira Cloud.
	Select the deep linking icon.
	Select Claude Code.
	Enter a custom full path to your coding workspace.
	Select Open in Claude Code to experience the work item context being passed to your agent.
