## Description

Plan work more effectively in Jira business projects by saving custom timeline views. Project admins can save timeline configurations at the project level so teams can quickly return to the same planning context, while individual users can still personalize their own view and reset back to the saved version when needed. To get started with this change Go to your business project and select Timeline from the project navigation.
