## Description

Save time by using Rovo to draft release notes in Jira. Summarize key changes in your release with AI and communicate value to your customers and stakeholders more efficiently. To get started with this change: Go to your software space and select the Releases tab in the navigation.
	Select the version you want to generate release notes for.
	Select Release notes.
	Select the toggle next to Create with Rovo.
	Select Create with Rovo to open Rovo Chat and review your draft.
