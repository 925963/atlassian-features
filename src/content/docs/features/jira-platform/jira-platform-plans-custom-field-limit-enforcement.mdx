## Description

Jira now enforces a limit of 40 custom fields per plan to improve backend performance and ensure a faster loading experience. If your plan already exceeds this limit, you can continue to use and remove existing custom fields, but you won't be able to add new ones until the total count is below 40. Open your plan in Jira.
	Select the More actions (three dots) menu, then choose Plan settings.
	Select the Timeline tab to view and manage your custom fields.
