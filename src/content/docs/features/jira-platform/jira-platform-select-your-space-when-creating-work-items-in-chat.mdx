## Description

Stay in your flow and capture work the moment it comes up. The /create-work-items skill in Jira now lets you view and select your space directly in chat so the right work lands in the right place, without switching apps. Open your chat app where Jira is integrated.
	Use the /create-work-items skill in your conversation.
	Select the space where you want to create the task using the new space selector.
	Review the work items generated and select Create.
