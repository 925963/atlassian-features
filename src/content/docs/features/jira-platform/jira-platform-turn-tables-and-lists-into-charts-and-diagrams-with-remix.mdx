## Description

Understand complex information faster by transforming text, tables, and lists in Jira work item descriptions into instant charts and diagrams. Remix is an AI-powered feature that lets you generate personal visualizations without changing the original content — so you can explore data your way. Open a Jira work item and select the description to enter edit mode.
	Hover over a table, list, or text block to reveal the element toolbar.
