## Description

Jira admins can now use an improved audit log to track and troubleshoot changes. This update provides a more consistent experience for managing important events, such as permission changes and configuration updates, helping you maintain better visibility and security. In Jira, select Settings, then System.
	From the sidebar, select Audit log.
