## Description

Jira now supports smart links within short text fields in the List view. This update allows you to view and interact with rich previews of URLs directly from your table view, making it easier to access linked information without leaving your current context. To get started with this change Go to the List view in a Jira Space.
	Locate a short text field that contains a URL.
	View the URL rendered as a smart link.
