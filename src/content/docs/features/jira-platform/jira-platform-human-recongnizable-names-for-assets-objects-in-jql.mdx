## Description

We've updated Jira Query Language (JQL) so that Assets objects now display as human-readable names instead of Atlassian Resource Identifier (ARI) values. This makes writing and validating JQL faster and easier. To view this change: Open your Jira app and navigate to Filters.
	Enter a JQL query that includes Assets object operands.
	View the improved results containing the Asset Objects' names.
