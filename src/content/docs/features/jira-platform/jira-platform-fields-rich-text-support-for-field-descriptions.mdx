## Description

Jira admins can now use rich text to create and edit field descriptions in Atlassian Administration. This change allows for better formatting and clearer instructions for users, while also increasing the character limit to 4,000 visible characters (up from 255). In Jira, select the Settings icon in the top navigation.
	Go to Work items, then Fields.
	Select Create field or select Edit on an existing field to use the rich text editor for the description.
