## Description

We've refreshed the add status experience in the workflow editor to make creating and choosing statuses clearer. We updated the wording throughout the dialog, and moved the create option into a fixed footer so it's always visible while you scroll. To get started with this change: Edit a workflow.
	Select Add status in the toolbar at the top.
	Select an existing status to add or create a new one.
