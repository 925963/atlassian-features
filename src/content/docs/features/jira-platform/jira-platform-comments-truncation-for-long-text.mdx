## Description

Jira now truncates long comments to help you scan through your work more efficiently. This change keeps your issue view clean and organized by showing only the beginning of lengthy discussions, allowing you to focus on the most relevant information first. Open any issue in Jira that contains a long comment.
	Select See more at the end of the truncated text to view the full comment.
	Select See less to collapse the comment back to its truncated view.
