## Description

he Deployments in Jira feature will now have a new home within Development in Jira. Starting July 12, 2026, you’ll no longer have separate Deployments page in your software space in Jira, and Development will be the only place to access the deployment features. You can start using Development today, where all deployment features, including your existing app connections and data, are already available. There you’ll also find data from other integrated apps, key metrics, work suggestions, and more
