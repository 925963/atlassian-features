## Description

Save time and reduce manual effort by using the Jira Triage Agent to automatically review and route incoming work. The Jira Triage Agent uses AI and your Teamwork Graph to analyze the context of new work items and suggest updates for fields like priority, labels, and assignee. It also identifies duplicate or similar work items within your space, helping your team stay organized and focused on the right tasks. Go to your Jira board and select the agent picker from the status column header.
