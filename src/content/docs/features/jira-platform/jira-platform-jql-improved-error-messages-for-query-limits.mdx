## Description

We’ve updated how Jira handles large JQL queries to ensure search remains fast and reliable. When a query exceeds specific thresholds for functions like membersOf() or organizationMembers(), Jira now provides a clear error message instead of failing silently or timing out. These changes help you refine your search criteria and maintain optimal app performance. To get started with this change Navigate to the Filters menu in Jira.
