## Description

We’re testing a smarter way to get AI agents working for you even faster. Some people in your organization may be part of an Agent Readiness experiment. This new check reviews your Jira work items to see if they have enough information for your agent to start immediately – skipping the planning phase so you get your results sooner. Assign a work item to an agent as you normally would. If the experiment is active, you’ll see a message: “Rovo is reviewing the work item.”
