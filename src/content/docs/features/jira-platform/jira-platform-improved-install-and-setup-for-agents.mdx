## Description

Installing and setting up an agent from the Browse agents section in Jira is now clearer and easier. The install flow shows you what's happening as the agent installs, and the steps to configure the agent after install are more guided, so it's simpler to get your agent set up and ready to use. In Jira, go to the Browse agents section.
	Select an agent, then select Install or Request depending on your permissions.
	Follow the guided steps to configure the agent after it installs.
