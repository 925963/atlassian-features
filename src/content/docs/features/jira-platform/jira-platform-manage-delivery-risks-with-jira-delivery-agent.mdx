## Description

Jira now includes the Jira Delivery Agent, a Rovo Agent designed to help you manage your work more effectively. This agent reads Jira work, identifies delivery risks early, and turns issue activity into clear, actionable updates. By using the Jira Delivery Agent, you can make more informed decisions and keep your team on track. To use the Jira Delivery Agent: Open Rovo Chat in your Jira space.
	Select the Rovo dropdown menu.
