## Description

You can now add a Confluence whiteboard to your work item using a slash command. By adding a whiteboard to your work item, it makes brainstorming and visualizing ideas more easier. To add a whiteboard to a work item: Select the Description or Comment section in a work item.
	Type / to open the menu and select Whiteboard from the list of options.
