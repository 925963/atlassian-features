## Description

Save time and streamline your workflow by discovering and installing coding agents directly from the agent picker in Jira. This update helps you find the right tools for your development tasks without leaving your current context. Open the agent picker in Jira.
	Select the Explore coding agents footer link to open the Browse agents modal.
	Select an agent to install it and start using it in your work.
