## Description

Save time and reduce repetitive tasks in Jira with AI-suggested fields. When you create a work item, Atlassian Intelligence analyzes your space's historical field-usage patterns and similar work items to suggest contextually relevant values for assignee, parent, priority, components, custom labels, custom single select, and custom multi select fields.
