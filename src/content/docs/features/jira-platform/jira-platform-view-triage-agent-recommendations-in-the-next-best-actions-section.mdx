## Description

Save time by viewing and actioning triage agent recommendations directly from the Next best actions section in Jira. When the triage agent is configured as part of a transition in your workflow, it automatically suggests field updates that now appear at the top of the work item view for better visibility. To view this change: Open a work item in Jira that has transitioned to a status where the triage agent is configured.
	Locate the Next best actions section at the top of the work item view.
