## Description

Jira and the Projects app are now natively integrated. A built-in Project field is now available by default on software and business Jira spaces, making it easier to connect work items to projects and track them across your organization. Go to a software or business space in Jira.
	Open an existing work item or create a new one.
	Select the Project field.
	Select an existing project from the list, or create a new one from the picker.
	To view linked work items, go to the project in the Projects
