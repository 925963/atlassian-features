## Description

Blocks bring faster editing, reusable patterns, and always-in-sync content across apps. This new feature set allows you to create content once and reuse it across Jira and Confluence with live-syncing, ensuring your information is always up to date. You can also quickly transform content types using the new block menu and save polished sections as templates for future use. Open any editor and select the drag handle (⋮⋮) to access new block-level options.
	Select Change format to convert a block
