## Description

Improve a work item in one click with a new out-of-the-box Rovo agent in Jira. This ready-to-use agent scopes your work item for you. It gathers relevant context, asks a few clarifying questions, and suggests a stronger description you can accept. There's no setup, and no need to pick an agent first: scoping your work is now its own standalone action. Open a work item in Jira.
