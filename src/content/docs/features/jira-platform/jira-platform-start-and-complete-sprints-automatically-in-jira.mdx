## Description

Save time and keep your team on track by scheduling sprints to start and complete automatically in Jira. To get started with this change: Go to your scrum board and select the Backlog.
	Find the sprint you want to automate and select More actions (...), then select Edit sprint.
	Select Automatically start and complete sprint.
	Set your preferred Start date and End date.
	Choose whether open work items should move to the backlog, a new sprint, or to an existing sprint on completion.
	Select Save.
