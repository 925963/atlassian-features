## Description

Save time and reduce setup effort by using Rovo to configure your new Jira spaces. By providing a simple prompt, Rovo suggests the best space name, key, work types, and statuses based on your team's specific needs and existing context. We're currently experimenting with this feature, so it may not be available to everyone yet. Hover over Spaces in the side navigation, then select Create space 
	Under space templates, select Create with Rovo > Get started with a prompt.
