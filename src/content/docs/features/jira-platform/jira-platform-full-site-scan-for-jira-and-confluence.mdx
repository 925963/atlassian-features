## Description

Full site scan lets organization admins and Guard Detect scan all Jira and Confluence content to find sensitive data and export results for follow‑up. Full site scan is available to Guard Premium customers and can be launched from the Guard admin experience under the Content scan tab in the header. When you start a content scan, you can select what you’d like to scan. Make sure you’ve set up any custom detections you wish to scan before you start a content scan.
