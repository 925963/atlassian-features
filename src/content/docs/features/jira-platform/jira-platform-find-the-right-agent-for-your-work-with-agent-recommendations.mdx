## Description

Save time and reduce guesswork with agent recommendations in Jira. We’ve updated the agent picker and browse experience to surface the most relevant agents based on your current task, workflow, and recent activity. These improvements, powered by a new recommendation API, help you quickly identify which agents can best assist with your work items. To find and use the recommended agent: Open a work item in Jira.
	Select Agents at the top of your work item.
	Review the Recommended agent at the top
