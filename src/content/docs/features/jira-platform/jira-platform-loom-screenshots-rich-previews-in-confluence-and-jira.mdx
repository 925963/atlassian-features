## Description

Loom screenshot links pasted into Confluence or Jira now render as rich Smart Link previews instead of plain text URLs. This improvement provides immediate visual context and brings screenshot links to parity with Loom video links. Copy a link to a Loom screenshot.
	Paste the link into a Confluence page or Jira work item.
	Select the link to switch between Inline, Card, and Embed views.
