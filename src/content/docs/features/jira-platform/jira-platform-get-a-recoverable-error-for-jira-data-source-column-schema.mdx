## Description

Jira now displays a recoverable error message instead of an indefinite loading state when a data source request lacks an available column schema. This improvement helps you understand the issue and provides a way to resolve it by refreshing the data source. Go to a page or dashboard that contains a Jira data source.
	If the data source encounters a missing column schema error, locate the error panel.
	Select Refresh within the error panel to recover the column schema and display your data.
