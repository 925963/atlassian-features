## Description

Get more accurate responses by refining the output of your chats with Rovo agents. You can now provide follow-up instructions to an agent directly in the work item view, ensuring the final response meets your specific needs without starting a new chat. Start a Rovo Chat with an agent on a work item.
	Review the initial response generated by the agent.
	Enter follow-up instructions in the chat to refine the response.
