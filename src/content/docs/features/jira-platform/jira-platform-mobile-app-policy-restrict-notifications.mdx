## Description

Organization admins can now control how push notifications appear in Atlassian mobile apps to help prevent data leaks. This new restriction in the mobile app policy allows admins to either hide sensitive notification content or block push notifications entirely for Jira, Confluence, and Rovo mobile apps. Go to admin.atlassian.com.
