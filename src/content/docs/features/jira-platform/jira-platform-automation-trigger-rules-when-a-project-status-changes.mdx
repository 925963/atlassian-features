## Description

Save time and keep your team informed by automating actions whenever a Project status changes. This new automation trigger allows you to streamline workflows such as sending notifications without manual intervention. To get started with this change Create an automation rule and click Create rule.
	Under Add a trigger, search for and select Project status changed.
	Select the projects you want the automation to run for. Leave this blank to monitor all projects in your instance.
	Select the status
