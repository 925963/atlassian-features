## Description

Monitor and manage work across all your spaces in one place with dedicated views for incidents and changes. These views, located in the Operations tab, remove the need for custom filters or manual searches, helping you stay on top of operational work more efficiently. To get started with this change: Select Operations from the sidebar in Jira.
	Select Incidents or Changes to view work items from all spaces.
	Use the search bar or filters to refine the list of work items.
