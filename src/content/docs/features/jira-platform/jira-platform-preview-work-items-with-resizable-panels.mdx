## Description

Jira is replacing the detail view in the List view and Global Search with a resizable preview panel. This change allows you to view and interact with work items in a side panel without losing your place in the list. You can also preview Confluence pages, projects, and goals without opening new browser tabs, helping you move quickly between work items and reduce tab overload. To get started with this change: Go to the All work tab or use Global Search in Jira.
