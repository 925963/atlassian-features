## Description

Update custom select fields directly from the command palette while viewing work items in Jira. This change helps you save time by managing specific details without leaving the work item view or navigating through multiple menus. To get started with this change Open a work item to enter the work item view.
	Open the command palette by pressing command + K (Mac) or Ctrl + K (Windows).
	Search for the name of the custom select field you want to update.
	Select the field from the list of results.
