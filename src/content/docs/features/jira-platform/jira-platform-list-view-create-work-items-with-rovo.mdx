## Description

We've updated the empty state in the list view for Jira Software and business projects to help you get started faster. If your site has Atlassian Rovo enabled, you'll now see a Rovo-first landing state when a list is empty. This change allows you to quickly generate multiple work items using Rovo or use an enhanced inline creation form with AI-powered suggestions, making it easier to populate your project and organize your work.
