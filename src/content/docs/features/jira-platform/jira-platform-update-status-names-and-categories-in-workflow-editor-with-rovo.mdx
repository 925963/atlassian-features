## Description

You can now update status names and categories in the workflow editor using Rovo. Previously, the skill would remove and replace a status instead of updating it. The new update status action also notifies you if other workflows are using that status, helping you manage changes to your workflow more effectively. To update status names and categories using Rovo: Open the workflow editor in Jira.
	Select the Rovo icon to open the Manage Jira workflows skill.
	Enter a prompt to update a status name
