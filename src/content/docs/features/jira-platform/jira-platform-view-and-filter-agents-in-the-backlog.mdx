## Description

You can now see which agents are active in your backlog and filter work items by agent. This makes it easier to collaborate and manage work in real-time. To view and filter agents in the backlog: Open your Jira project and select Backlog from the sidebar.
	Look for the agent session icon at the right side of the work items, next to the Assignee icon.
