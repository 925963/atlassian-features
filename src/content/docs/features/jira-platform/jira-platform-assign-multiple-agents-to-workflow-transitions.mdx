## Description

Manage your workflow automation directly from your board by assigning multiple agents to specific column transitions. You can customize each agent’s behavior with optional prompts without ever opening the workflow editor. This gives you more granular control over how work moves through your board, saving you time and increasing your team's automation flexibility. To get started with this change: Go to your board and select the Add agent icon in the column header.
