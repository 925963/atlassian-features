## Description

Jira users can now filter work based on assigned agents and their current states. This update to the filter panel helps you manage work items more effectively as you incorporate agentic workflows into your experience. To get started with this change: Open a Board or List view in your space.
	Select Filter.
	Create a new filter using the fields Agent or Agent state.
	Choose the agent or agent state you want to filter by.
	Select Apply.
