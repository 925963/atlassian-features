## Description

Jira admins can now manage user access and roles more efficiently with a new global access management page. This update provides a central location to view and control how users join and interact with Jira, helping you maintain security and streamline onboarding. Go to Jira settings, then System.
	Select Access management from the sidebar.
	Review and update your global access settings as needed
