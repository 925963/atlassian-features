## Description

Get a more complete picture of team activity in Jira by viewing all Rovo agent sessions associated with a work item. Previously, agent sessions were private to the person who started them, but now anyone with access to a work item can see all sessions started by their team, making automated work visible to everyone and accountable. To view this change: Open a work item in Jira where team members are using Rovo agents.
	View the agent session cards to see all active sessions started by your team.
