## Description

Monitor and improve agent adoption across your team with the new Agents dashboard in Jira. This dashboard provides visibility into how your team uses agents, helping you identify trends and drive consistent engagement to maximize the value of your Atlassian apps. Go to your Jira spsce.
	Select Reports from the space navigation.
	Select Agents from the list of available dashboards.
