## Description

Save time and improve workflow accuracy in Jira by automatically assigning issues to teams based on information in custom fields. You can now use the Assign issue action in the automation rule builder to assign an issue to the team stored in a People custom field, such as an On-call field. To get started with this change Go to Project settings, then Automation.
