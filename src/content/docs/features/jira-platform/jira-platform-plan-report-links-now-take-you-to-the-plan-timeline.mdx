## Description

Access live data and the latest updates by opening your plan report links directly in the plan timeline. We’re retiring the static plan report page to ensure you’re always working with the most current information. If a link can't be matched to its original plan, it will open your list of plans instead. Ability to create new plan reports was deprecated in June 2023.
