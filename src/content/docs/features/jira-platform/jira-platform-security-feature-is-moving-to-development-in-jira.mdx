## Description

The Security in Jira feature will now have a new home within Development in Jira. Starting July 12, 2026, you’ll no longer have separate Security page in your software space in Jira, and Development will be the only place to access the security features. You can start using Development today, where all security features, including your existing security container connections and data, are already available.
