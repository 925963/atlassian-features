## Description

Jira now enforces limits for configuration entities, including field options, workflows, statuses, components, priorities, versions, security levels, and permission grants, to help maintain app performance and stability. When an entity reaches its maximum threshold, Jira blocks the action and provides guidance on how to optimize your usage. To get started with this change Go to the Jira administration area where you manage the relevant entity.
