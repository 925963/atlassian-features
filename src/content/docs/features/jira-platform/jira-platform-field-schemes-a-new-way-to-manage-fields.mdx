## Description

Jira admins can now use field schemes to manage which fields are available and required for different work types. This new experience replaces the legacy field configurations and field configuration schemes, providing a more intuitive way to ensure projects only include relevant fields. To use field schemes: Go to Jira settings, then Work items.
	Select Field schemes from the sidebar.
	Choose an existing scheme to edit or select Create field scheme to start a new one.
	Use the Advanced settings
