## Description

Admins can now create company-managed spaces in Jira using a simplified one-step wizard. This update streamlines the space creation process, allowing you to set up and configure your spaces more efficiently. In Jira, go to Spaces, then select Create space.
	Choose a space template and select Use template.
	Select Company-managed as the space type.
	Enter your space details in the one-step wizard and select Create space.
