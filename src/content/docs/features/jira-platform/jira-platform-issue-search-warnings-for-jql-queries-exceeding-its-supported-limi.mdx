## Description

Jira now displays a warning banner when a Jira Query Language (JQL) search when it exceeded its supported limit. This helps you identify when a search might not return all expected results due to system limits, allowing you to refine your query for better accuracy. To get started with this change Navigate to the Issues menu in Jira.
	Select Search for issues.
	Enter a JQL query in the search bar.
