## Description

New users joining Jira will now land directly on the For you page instead of landing on an empty page or a generic directory. This change helps new team members quickly find relevant work and get started with their tasks in Jira without needing to navigate through multiple menus. To view this change: Log in to Jira as a new user.
	View your personalized For you page.
	Select a task or project from the page to begin working.
