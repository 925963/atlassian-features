## Description

Save time when moving data into Jira Cloud by importing CSV files directly into your existing spaces. This update to the CSV importer allows you to add new work items to a space and map status values from your file to existing Jira statuses, ensuring your data aligns with your current workflows. You need to be a system or organization admin to do this. In Jira, go to Settings, then System.
