## Description

Save time and stay organized in Jira with the refreshed Agent sessions tab. You can now view development artifacts for Jira coding agents (such as pull request links) directly within coding agent sessions and use improved filtering to find the information you need faster. In Jira, navigate to the For You page.
	Select the Agent sessions tab to view your active and past sessions.
	Use the new filter options to narrow down your session list.
