## Description

Save time and streamline your development workflow by using the Claude agent action in Jira Cloud automation. This new action allows you to integrate Claude, a third-party AI agent, directly into your automation rules to perform complex tasks and process information within Jira Cloud. Go to your Jira space and select Space settings, then Automation.
