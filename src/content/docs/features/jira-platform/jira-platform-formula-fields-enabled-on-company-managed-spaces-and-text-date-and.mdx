## Description

Jira formula fields are now available in company-managed spaces. Jira formula fields support text, date, and duration outputs, enabling complex calculations across your work. You can search and sort by formula field values using Jira Query Language (JQL) to organize and prioritize your work items. These features are available in both company-managed and team-managed spaces. Create a formula field
