## Description

Forge apps that use UI modifications now work consistently when you open a work item (referred to as an issue in the API) in a modal through Forge apps in Jira Cloud and Jira Service Management (agent view). Previously, these modifications were not applied to modals triggered by apps. This change ensures that your UI modifications — such as hiding fields, setting values, or making fields read-only — apply correctly regardless of how you open the work item.
