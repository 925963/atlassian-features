## Description

We’ve removed access to the old workflow editor in Jira. This change ensures all users have a consistent experience using the updated workflow editor to manage how work moves through its lifecycle. Go to Jira settings, then Work items.
	Select Workflows.
	Select More actions (•••), then Edit on any workflow to open the current workflow editor.
