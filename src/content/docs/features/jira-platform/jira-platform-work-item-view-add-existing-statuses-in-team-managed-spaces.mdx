## Description

In Jira team-managed spaces, you can now search for and select an existing status when adding a status from the Status field in the work item. If the status you need does not exist, you can create a new one. Open a work item in a team-managed Jira space.
	In the Status field, select Add status.
	Search for and select an existing status.
	If you need a new status, enter its name and select Create status.
