## Description

Manage your workflows more efficiently with new transition options and a clearer layout in the workflow editor. These updates help Jira admins save time when creating statuses and provide better visibility into how work moves through a project. To get started with this change: Go to Space settings, then Workflows.
	Select Edit on the workflow you want to update.
	Select Add status to see the new Allow transitions from any status checkbox.
	Select any status on the diagram to view the separated I
