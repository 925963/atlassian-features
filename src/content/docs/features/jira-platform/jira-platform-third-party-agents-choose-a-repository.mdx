## Description

Save time when using third-party agents in Jira by choosing the specific repository you want the agent to use. By selecting a repository before the agent starts its task on a work item, you ensure the agent has the right context and avoid unnecessary planning steps. Open a work item in Jira.
	Select a third-party agent to perform a task.
	Select the repository you want the agent to work with from the list or type one in.
