## Description

This update restores the ability to view work items with parent work items from other spaces when Show hierarchy is enabled in the List view in Jira. Open the List view in any Jira space.
	Select More actions (···) and toggle on Show hierarchy. Work items having parent work items in another spaces should now be visible in the List view.
