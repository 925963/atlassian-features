## Description

You can now group work items by agent in the list view and add the Agent sessions field as a column in the list and global search views. See agent workloads at a glance and track delegated work without opening individual work items. To group work items by agent in your list: Go to the list view in Jira.
	Select Group from the view options.
	Select Agent from the dropdown menu to organize your work items.
