## Description

Organize your work more effectively in Jira by grouping work items by agent in the List view. This update allows you to see a structured, at-a-glance view of agent workloads, making it easier to identify, triage, and act on delegated work. Open a list view or perform a global search in Jira.
	Select Group from the view options.
	Select Agent from the dropdown menu to organize your work items.
