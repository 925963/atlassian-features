## Description

Formula fields in Jira Plans now recalculate based on scenario values, allowing you to see up-to-date derived values while exploring changes in your timeline. Previously, formula fields only reflected data from the committed Jira issue, which could lead to inconsistent information when testing "what if" scenarios.
