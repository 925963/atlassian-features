## Description

Save time and stay organized with My agent sessions, a new view on the For you page in Jira that lets you monitor and manage all your agent work from a single place. See which sessions need your input and take action immediately without having to search through individual work items. To get started with this change: Open Jira.
	Select For you from the navigation menu.
	From the My agent sessions view, select any session to take action.
