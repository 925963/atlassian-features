## Description

Organize your work more effectively in Jira by grouping work items by date and date-time fields in the list view. This update allows you to see your schedule at a glance and manage your team's priorities with better clarity by organizing work based on deadlines and timelines. To get started with this change: Open your project and select the List view.
	Select the Group by menu from the toolbar.
	Select a date field, such as Due date, from the list.
