## Description

Save time in Jira by expanding or collapsing all top level work items in the list view with a single click. This update allows you to quickly view or hide child work items across your entire list. Furthermore, when grouping is applied, this feature allows you to quickly expand or collapse all groups. To expand work items in list view: Go to your Space, then select the List/All work tab.
