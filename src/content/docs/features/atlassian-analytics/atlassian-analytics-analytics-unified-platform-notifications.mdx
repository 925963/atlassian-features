## Description

Atlassian Analytics now uses the standard Atlassian platform notification drawer. This update ensures that all your notifications for chart comments, dashboard updates, and @mentions appear in one central location alongside notifications from other Atlassian apps. Open the Analytics app.
	Select the Notifications bell icon in the top navigation.
	View and manage your notifications in the new platform drawer.
