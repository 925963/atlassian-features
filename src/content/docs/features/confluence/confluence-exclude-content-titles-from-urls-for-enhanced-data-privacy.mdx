## Description

Confluence admins on Enterprise plans can now choose to hide content titles from the address bar for pages, blogs, and live docs. This security setting helps protect proprietary information by ensuring that titles aren't visible in the URL when links are shared or copied. To exclude content titles from the address bar: Go to Confluence administration, then Settings.
	Select Security, then select Security Configuration.
	Select Exclude content titles from URLs to enable the setting.
	Select Save.
