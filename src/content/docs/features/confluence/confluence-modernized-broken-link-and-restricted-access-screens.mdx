## Description

We’ve updated the design of broken link and restricted access screens to provide a more modern visual experience. These changes also include clearer guidance when you encounter missing content or access issues, helping you understand the next steps. To view this change: Navigate to a Confluence page that doesn’t exist or a page you don’t have permission to view.
	View the updated illustrations, typography, and clearer guidance.
