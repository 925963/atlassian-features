## Description

Confluence now has Create with Rovo button in the template library right rail. This update allows you to quickly find and iterate on template content with Rovo, helping you generate high-quality content and automate tasks more efficiently within Confluence. To get started with this change: Open an existing Confluence page or create a new Confluence page.
