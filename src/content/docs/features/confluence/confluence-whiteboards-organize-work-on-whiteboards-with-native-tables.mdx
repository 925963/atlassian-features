## Description

Whiteboards now support native tables, so teams can organize work in a structured grid without leaving the canvas. Create a table from the toolbar, choose its dimensions before placing it, edit cell content, add or remove rows and columns, set headers, and resize the layout as work evolves. You can also paste supported HTML tables into a whiteboard as editable native tables. To get started with this change Open a whiteboard.
	Select Table from the toolbar, choose the number of rows and columns y
