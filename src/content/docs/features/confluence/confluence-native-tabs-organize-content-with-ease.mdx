## Description

Organize your Confluence docs more effectively with the new native tabs element. This feature allows you to group related information into a single, tabbed view, making it easier for your team to navigate complex content without cluttering the page. To get started with this change Open a Confluence doc in the editor.
	Type /tabs or select Tabs from the insert menu.
	Add your content into each tab section.
	Select Publish to see your organized content in action.
