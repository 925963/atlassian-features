## Description

Export Confluence pages as markdown (.md) files to easily reuse your content in developer workflows, external documentation tools, and note-taking apps. This plain-text format provides a portable way to move your work between platforms while maintaining structural simplicity. To export pages: Open the Confluence page you want to export.
	Select More actions (•••) in the top right corner.
	Select Export, then select Markdown.
