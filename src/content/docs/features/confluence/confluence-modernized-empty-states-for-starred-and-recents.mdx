## Description

We’ve updated the empty states for your Starred and Recent pages with new illustrations and clearer guidance. These updates help you find the right path to start creating or discovering content when you don't have any activity yet. To view this change: Open Confluence.
	From the side navigation bar, select Starred or Recent.
	If you haven't starred any pages or viewed any recently, you'll see the new modernized empty state.
