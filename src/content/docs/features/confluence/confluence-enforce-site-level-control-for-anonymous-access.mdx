## Description

Confluence admins can now permanently enforce site-level control over anonymous access. This ensures that when anonymous access is turned off for your site, space admins can't override it at the space level. This update helps you maintain stronger governance and consistent security across all spaces. This update is available for all paid Confluence Cloud customers on role-based access model.
