## Description

Save time and refine your content with a new keyboard shortcut for Atlassian AI. When you finish writing a block of text in Confluence, you can now press the Tab key to see a prompt that suggests using Improve writing to polish your work. To get started with this change Open a page in Confluence.
	Write a block of text in the editor.
	Press the Tab key on your keyboard.
	Select the prompt to run Improve writing on your content.
