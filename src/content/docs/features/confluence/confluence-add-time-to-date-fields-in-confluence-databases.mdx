## Description

Track time-sensitive data with greater precision by adding time to your date fields. This update allows you to include a specific time component, giving your team more flexibility when managing deadlines or schedules in Confluence databases. You can choose between 12-hour and 24-hour formats. Open a Confluence database and select the Date field you want to update.
