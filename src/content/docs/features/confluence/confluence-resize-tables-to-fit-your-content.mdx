## Description

Resize tables in Confluence to match the width of your content with a single select. You can now adjust the overall table and column widths instantly, ensuring your data is presented clearly without being overstretched or compressed. Open a Confluence page in the editor.
	Select the table you want to resize.
	Select the Fit to content button from the table toolbar. This option isn’t available for nested tables.
