## Description

We’ve updated the empty states for starred and recent items in your navigation to provide a cleaner, more consistent experience. These new designs replace older illustrations and styling, helping you stay focused on your work and reducing visual clutter when you're just getting started. To view this change: Open Confluence.
	From the side navigation bar, select Starred or Recent.
	If you haven't starred any items or viewed any pages yet, you'll see the new modernized empty state designs.
