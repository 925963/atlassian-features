## Description

Confluence admins can now disable default roles site-wide and choose which roles power system operations. This change allows you to simplify role selectors by removing unused default roles and gives you more control over how access is automatically assigned for operations like setting the space owner and default guest access. To manage your site's default roles and system operations: Go to Confluence settings, then select Permissions.
	Select Space roles to disable or restore a default role.
