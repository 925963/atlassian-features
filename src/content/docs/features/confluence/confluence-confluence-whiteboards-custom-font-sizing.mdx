## Description

Customize the look of your Confluence whiteboards with precise font sizing. This update gives you more flexibility to create visual hierarchy and ensure your text fits perfectly within sticky notes, shapes, and text boxes. To get started with this change: Open a whiteboard in Confluence.
	Select an element containing text, such as a sticky note or shape.
	Select Text styles (Tt icon) in the toolbar.
	Enter a number in the font size input box to set the size of your text.
