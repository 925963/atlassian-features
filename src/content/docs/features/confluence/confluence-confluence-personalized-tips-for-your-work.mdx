## Description

Discover relevant Rovo features in the flow of your work with personalized tip emails. Confluence users on sites with Rovo enabled will now receive short, task-based tips triggered by specific actions, such as creating a page or reading a long document, to help them work more productively with Rovo. To get started with this change: Complete a common task in Confluence, such as creating a page or reading a long document.
