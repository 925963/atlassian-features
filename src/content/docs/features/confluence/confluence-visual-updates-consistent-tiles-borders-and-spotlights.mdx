## Description

We’ve updated several visual elements across Confluence to provide a more consistent and modern experience. These changes include migrating various components and spotlights to a standardized tile system, improving how labels are categorized, and updating border styles to align with the Atlassian Design System. To get started with this change: Open any page or space in Confluence.
	View your content, including labels, tile-based components, and in-product spotlights, to see the updated styling.
