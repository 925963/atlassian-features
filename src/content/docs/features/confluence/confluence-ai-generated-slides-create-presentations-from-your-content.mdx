## Description

Save time by using AI to generate presentation slides directly from your content in Confluence. This new feature allows you to transform your content into structured slides, making it easier to share information and collaborate with your team. To get started with this change: Open a page in Confluence.
	Select the Create menu from the top toolbar.
	Choose Select slides from the list of options.
	Review the generated slides to fit your needs.
	Revise the slides using AI-first editing.
