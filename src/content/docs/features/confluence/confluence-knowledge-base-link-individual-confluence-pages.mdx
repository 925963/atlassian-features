## Description

Jira Service Management admins can now link individual Confluence pages and their child pages as knowledge base sources. This update provides finer control over the content surfaced to agents and help-seekers across the Help Center, portal, and work item view. Go to your service space in Jira Service Management, then select Space settings.
	Select Knowledge base.
	Select Add knowledge, then choose a Confluence space.
	In the Specific content menu, select the individual page you want to link.
