## Description

Confluence now features a floating table of contents to help you navigate long pages and live docs more efficiently. This persistent navigation tool allows you to jump between sections without scrolling back to an embedded macro, saving time and keeping you oriented within your content. Open a page or blog post in Confluence.
	Select the table of contents button in the right-side object sidebar.
	Select any heading from the outline to scroll directly to that section.
