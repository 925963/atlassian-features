## Description

Save time when adding status lozenges to your pages in Confluence. The status popup now suggests statuses that are already being used on the page, helping you maintain consistency across your content without manual typing. To choose from an already used status from the page: Open a page in the Confluence editor.
	Type /status or select Status from the insert menu to add a status lozenge.
	Select the status lozenge to open the status popup.
	Choose from the suggested statuses already present on y
