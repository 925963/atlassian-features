## Description

Confluence administration has a new look and feel to help you find the tools and settings you need more efficiently. We've reorganized the sidebar into logical, functional sections, and updated the names of several tools to better reflect their purpose. These changes make it easier to manage access and discover the right settings in Confluence. To get started with this change: Go to Confluence administration.
	Follow the 3-step guided tour to see where your tools and settings have moved.
