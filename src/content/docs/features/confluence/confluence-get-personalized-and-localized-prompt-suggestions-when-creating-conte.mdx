## Description

Save time and get started faster with personalized prompt suggestions in Confluence. Atlassian Rovo now generates prompt tiles that are action-oriented, grounded in your recent activity, and localized to your preferred language. Create new content items with Rovo To get personalized prompt suggestions: Select Create in the top navigation bar of Confluence.
	Select Create with Rovo.
	Review the personalized prompt tiles in the staging modal to see suggestions based on your recent work.
