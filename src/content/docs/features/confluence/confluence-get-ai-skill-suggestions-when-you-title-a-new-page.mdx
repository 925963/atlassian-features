## Description

Confluence now suggests relevant Rovo skills when you start a new page with specific keywords. If the title matches a known content type — like a PRD, how-to guide, research summary, or action plan — a banner appears inline with a one-click prompt to launch the matching skill directly in Rovo Dev, helping you get started faster with AI-powered content creation.
