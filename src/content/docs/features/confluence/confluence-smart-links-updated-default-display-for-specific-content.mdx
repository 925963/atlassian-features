## Description

Certain URLs now automatically display as cards or embeds when you insert them into a Confluence page. This update provides a richer, more visual experience for your content by default, while still allowing you to manually change the display type to a URL, inline, card, or embed as needed. Open a Confluence page in the editor.
	Paste a supported URL into the page.
