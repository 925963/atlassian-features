## Description

Organizing your content in Confluence just got more accessible. You can now reorder pages in the page tree using keyboard shortcuts, providing a powerful alternative to mouse-based drag and drop. This change ensures that everyone, including keyboard-only users and those using assistive technologies, can easily structure their workspace. To move a page using keyboard shortcuts: Open the Move dialog for your page.
