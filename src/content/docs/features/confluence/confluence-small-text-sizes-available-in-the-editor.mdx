## Description

You can now change your text size to small in the editor across Atlassian apps like Jira and Confluence. This new formatting option helps you fit more information on the screen and create a clear visual hierarchy in your pages and issues. To apply small text size in the editor: Open the editor in your app.
	Highlight the text you want to resize.
	Select the Text size menu from the toolbar.
	Select Small.
