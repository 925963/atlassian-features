## Description

Confluence now restores the most recently seen emoji on a Live Doc instead of defaulting to a generic emoji. This change ensures that when you remove or replace an emoji, the restore action brings back the specific state you last saw, providing a more intuitive and predictable experience. To get started with this change Open a Live Doc that has a title emoji.
	Remove the emoji from the title area.
	Select the Restore option to bring back the most recently seen emoji.
