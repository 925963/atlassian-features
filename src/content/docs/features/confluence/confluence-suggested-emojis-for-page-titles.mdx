## Description

Confluence now suggests a contextually relevant emoji whenever you use AI to generate a page title. This update helps your pages look more complete and visually distinct with less manual effort. To get started with this change: Create a new page in Confluence.
	Paste content onto the blank page or select Suggest title in the title area.
	Review the generated title and the accompanying suggested emoji.
	Keep the suggestion as is, or use the standard emoji controls to change or remove it.
