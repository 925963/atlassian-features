## Description

Save time by using Rovo to generate automation rules in Confluence, Jira, and Atlassian Administration. You can now describe the automation you need in plain language, and Rovo will build the rule for you, making it easier to streamline your workflows without needing to manually configure every step. To view this change in Jira: Open Jira.
	Navigate to the space where you want to add the automation rule and select Space settings.
