## Description

Code blocks in Jira and Confluence now include several improvements that make technical content easier to write, format, and read. New code blocks can detect supported languages automatically, the language picker now surfaces recently used languages, the floating toolbar includes controls for formatting code and line numbers, wrap setting is now persistent and clicking the code block border selects the whole block for easier editing.
