## Description

Confluence now automatically suggests and applies a page emoji when you create a page using Create with Rovo. This enhancement uses AI to select a work-appropriate emoji based on your page content, helping you create more polished and visually distinct pages with less effort. In Confluence, select Create in the top navigation bar, then Create with Rovo.
