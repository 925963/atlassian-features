## Description

Confluence whiteboards now show the names of everyone who has modified a sticky note, rather than just the person who created it. This update helps teams in Confluence track contributions more accurately and understand the full history of ideas during collaborative sessions. To view all contributors on sticky notes in whiteboards: Open a whiteboard in Confluence.
	Select a sticky note with edits from multiple people.
	Select Show author from the sticky note toolbar to see the list of contributor
