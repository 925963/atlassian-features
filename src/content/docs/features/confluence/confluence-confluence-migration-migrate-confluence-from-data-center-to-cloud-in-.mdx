## Description

Organization admins can now migrate Confluence Data Center to Cloud using the migration center in Atlassian Administration. This adds Confluence support alongside the existing Jira migration capability, providing a self-serve experience to plan, run, and monitor Confluence migrations. Go to admin.atlassian.com and select your organization.
	Go to Data management, then Delta migration.
	Connect your Confluence Data Center source and create a migration plan.
