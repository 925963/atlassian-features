## Description

Save time and capture every detail by using Rovo to transcribe speech to text in Confluence’s new blank object experience for whiteboards and databases. This feature allows you to quickly convert spoken words into written content, making it easier to interact with Rovo Chat and create content on the go. In Confluence, go to any of your spaces and create a new database or whiteboard.
