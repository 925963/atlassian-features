## Description

Confluence Performance Insights gives admins self-serve visibility into site and content performance. Site admins on Enterprise sites can now monitor load times, identify slow pages, and understand how user network conditions or devices impact the experience in Confluence. This helps teams maintain a healthy site and improve user satisfaction by diagnosing performance issues without needing to contact support. To get started: Go to Confluence administration.
