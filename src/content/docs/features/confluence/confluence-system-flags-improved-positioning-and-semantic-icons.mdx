## Description

Confluence system flags now feature improved positioning and more semantically relevant icons to provide a more modern and intuitive experience. These updates ensure that success messages and other system notifications are clearly visible and easy to understand as you work in Confluence. To get started with this change: Perform an action in Confluence that triggers a system notification, such as adding a user or successfully saving a change.
