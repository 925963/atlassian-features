## Description

End users in Confluence can now request an edition upgrade to Premium from Standard. This gives users a direct way to express interest in advanced features, helping organizations understand demand for Confluence Premium. To get started with this change: Open Confluence as an end user who doesn’t have billing permissions on a Standard edition site.
