## Description

Organize your content more effectively in Confluence by nesting tables inside panels. You can now structure complex information within a single visual container, making your docs and tasks easier to read and navigate. To nest tables inside of panels: Open the editor in Confluence.
	Type /panel or select the panel element from the + button in the toolbar.
	Inside the panel, type /table or select the Table element to nest it within the panel.
