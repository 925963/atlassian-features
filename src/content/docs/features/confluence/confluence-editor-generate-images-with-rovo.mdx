## Description

Create custom images for your Confluence pages using Rovo. Enter a prompt to generate unique visual content that makes your pages more engaging and helps your communicate ideas effectively. To create custom images with Rovo: Open a Confluence page in the editor.
	Type /image to insert the image generator.
	Enter a description of the image you want to create.
	Select Submit.
