## Description

Confluence databases now include a timeline view that displays your entries in a date range format. This new view helps you track schedules and visualize work over time within Confluence. To use the timeline view: Open a database in Confluence.
	Select the + icon next to your existing views.
	Select Timeline from the view options.
	Configure the date fields you want to use for the timeline.
