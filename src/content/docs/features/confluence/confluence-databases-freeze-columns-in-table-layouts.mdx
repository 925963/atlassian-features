## Description

Manage large amounts of data more effectively in Confluence by freezing columns in your database table layouts. This update allows you to keep essential information visible while you scroll horizontally through other fields in the app. Open a database in Confluence and select the table layout.
	Open the field header menu for the column you want to freeze.
	Select Freeze up to this column to keep that column and all columns to its left visible while scrolling.
