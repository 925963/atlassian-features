## Description

When you view a page in Confluence that contains links from third-party apps you haven't authenticated yet, a new nudge will prompt you to connect those apps. This helps you see rich previews and live embeds immediately, ensuring you get the full context of the content without having to manually connect each link or switch between different tools. Open a Confluence page that contains unauthenticated third-party links.
