## Description

Rovo now provides insights to all users, not just admins. This change allows everyone in your organization to view analytics and charts about Rovo agent activity, helping teams understand how AI is used to automate tasks and improve productivity. Open Rovo from the top navigation bar.
	Select Agents.
	Select the Insights tab to view activity data.
