## Description

We’ve added Rovo Search, Chat, and Agents directly to the Home sidebar. This change makes it easier to get help from Rovo the moment you arrive in Home, without needing to switch between different Atlassian apps or search for where to start. To find and use the new Rovo navigation items: Select Home from the top navigation of your Atlassian app.
	Locate the Search, Chat, and Agents items in the left-hand sidebar.
	Select any of these items to start using Rovo immediately within the Home shell.
