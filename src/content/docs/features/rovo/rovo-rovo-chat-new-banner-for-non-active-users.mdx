## Description

Rovo now includes a banner to help users who have the app activated but haven't started using it yet. This change makes it easier for people to discover and begin using Rovo Chat to find information and get work done across their Atlassian apps. To get started with this change: Ensure that admins have enabled Rovo for your Atlassian site.
