## Description

Organization admins can save Rovo connectors as drafts during the configuration process. This makes it simpler to start a connector configuration and come back to it later, where previously you would need to publish it to save. Go to Atlassian Administration.
	Select Rovo from the sidebar.
	Select Connectors.
	Start creating a new connector or edit an existing one.
	Select Save as draft to keep your progress without publishing the connector.
