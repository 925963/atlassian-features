## Description

We’ve updated the interface for managing Atlassian Rovo MCP server access in Atlassian Administration. This visual refresh includes a new user consent screen to improve transparency when modifying access, while ensuring all your existing controls and permissions remain unchanged. Go to Atlassian Administration, then Rovo.
	Select Rovo MCP server, then Permissions.
	Choose the user or group you want to modify.
	Follow the prompts on the user consent screen to complete the changes.
