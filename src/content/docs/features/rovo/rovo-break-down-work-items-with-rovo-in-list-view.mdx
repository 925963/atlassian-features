## Description

Save time by using Rovo to break down parent work items into smaller tasks directly from the list view in Jira. This new feature in Jira and Jira business projects allows you to quickly generate child issues using AI-powered suggestions, helping your team stay organized and move faster. To get started with this change Open a Jira or Jira business project and select the List view.
	Select the + icon or the inline child creation area under a parent work item.
