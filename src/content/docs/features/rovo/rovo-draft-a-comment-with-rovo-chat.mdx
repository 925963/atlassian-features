## Description

Drafting comments in Confluence is now easier with a new quick action in Rovo Chat. When you open the Chat side panel, you can select a predefined prompt to help you compose and refine your page comments. To get started with this change Open a page in Confluence.
	Select Rovo Chat from the sidebar.
	Select Draft a comment from the suggested actions.
	Follow the prompts to describe what you want to say.
