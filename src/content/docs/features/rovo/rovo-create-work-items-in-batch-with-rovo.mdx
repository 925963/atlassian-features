## Description

Save time when using Atlassian Rovo to create multiple work items in Jira. You can now review, edit, and select multiple suggestions in a single preview card before creating them all at once. To get started with this change Open Rovo chat and enter a prompt to create multiple work items, such as "create 3 tasks for the marketing launch."
