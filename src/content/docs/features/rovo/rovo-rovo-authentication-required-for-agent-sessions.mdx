## Description

Rovo agents now show a clear indicator when they need you to log in to a third-party app, like GitHub, to continue. This makes it obvious why an agent has paused, and gets you back to your conversation faster. Open a chat session with an agent in Rovo.
	If the agent needs authentication, look for the message "Authentication is required to proceed."
	Select User settings in the message to go to your account settings.
	Log in to the required app.
	Return to the chat and select Connect to continue,
