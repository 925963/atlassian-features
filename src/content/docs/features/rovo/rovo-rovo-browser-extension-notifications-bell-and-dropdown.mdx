## Description

Stay informed with the new notifications bell and dropdown in the Rovo browser extension. This update allows you to view and manage your notifications directly from the extension's new tab page, ensuring you never miss an important update while you work. To get started with this change Open a new tab in your web browser to access the Rovo browser extension.
	Select the Notifications bell icon in the top navigation.
	View your recent updates in the dropdown menu.
