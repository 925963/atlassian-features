## Description

Organization admins can use Rovo to bulk invite people from a written list, Google Sheet, Excel spreadsheet, or CSV file shared in Rovo Chat. The skill can assign invited people to Atlassian apps and groups, helping admins provision access for multiple people more efficiently. To get started with this change Go to Atlassian Administration.
	Select Rovo from the side menu.
	In Rovo Chat, use the admin-bulk-invite skill.
