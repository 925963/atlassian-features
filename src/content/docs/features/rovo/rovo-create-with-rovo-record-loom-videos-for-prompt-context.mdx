## Description

Save time and provide clearer instructions by recording Loom videos directly within Confluence. When you use Rovo to create content, you can now record your screen to give the AI model more context about what you want to build. To get started with this change Select Create in the Confluence navigation, then select Create with Rovo.
	Select Prompt with Loom video in the prompt box.
	Record your video using the full screen.
