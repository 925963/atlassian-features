## Description

We've introduced a new modal in Atlassian Rovo that simplifies how you create and configure agents. This update provides a more intuitive experience for building agents, helping you automate tasks and surface knowledge across your Atlassian apps more efficiently. Open Rovo from the top navigation bar.
	Select Agents from the side menu.
	Choose Create agent to open the new configuration modal.
