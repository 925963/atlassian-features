## Description

Organization admins can now access an improved dashboard in Loom to better manage their organization. These updates to the admin overview provide clearer visibility into workspace security, team activity, and license usage, while also enabling faster data exports for large organizations. Log in to your Loom account.
	Select Settings, then Organization.
	Select Overview from the sidebar to view the improved dashboard.
