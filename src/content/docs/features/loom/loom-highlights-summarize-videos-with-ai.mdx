## Description

Save time by getting personalized video summaries in Loom. This new feature uses Rovo to create highlights based on transcript data and your personal preferences, so you can quickly understand the key takeaways from any video without watching it in full. Open a video in Loom.
	Select the Highlights tab located in the side panel.
	Review the personalized summary generated by Rovo.
