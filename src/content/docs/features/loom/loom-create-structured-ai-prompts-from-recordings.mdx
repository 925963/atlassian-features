## Description

Loom users can now use Video Prompt mode in the Chrome extension to transform screen recordings into structured, context-rich prompts for AI agents. Loom automatically generates an Action Plan that captures your voice, screen interactions, and tehnical context, making it easier to create Jira work items or provide clear instructions to AI tools like Atlassian Rovo. Record video prompts for AI agents To start using video prompts: Open the Loom Chrome extension and select Video Prompt mode.
