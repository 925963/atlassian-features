## Description

Save time and capture every detail by using Rovo to transcribe speech to text in Atlassian apps. This feature allows you to quickly convert spoken words into written content, making it easier to interact with Rovo Chat and create content on the go. To get started with this change: Open an Atlassian app, such as Confluence or Jira.
	Open Rovo Chat or select Create with Rovo where you would need to type a prompt.
	Select Start dictation (the microphone icon).
	Speak your prompt and select Finish d
