## Description

Metric improvements are available for Goals. Users can now add manual metric data outside updates, delete eligible metric values, see metric and target activity history, and enjoy a redesigned metric chart. To review and use metric improvements: Go to the Overview tab of a success measure type goal that has a metric attached.
