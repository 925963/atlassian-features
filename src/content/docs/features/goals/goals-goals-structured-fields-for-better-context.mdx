## Description

Capture clearer and more consistent goal context in Atlassian Goals with new structured fields. The Overview tab now includes separate prompts for your goal description, why the goal is important, and how you will measure success. To get started with this change: Open an existing goal and select the Overview tab.
	Select Edit to add content to the new fields.
	Enter details into Why is this goal important? and How will you measure success?
	Select Save to update your goal.
