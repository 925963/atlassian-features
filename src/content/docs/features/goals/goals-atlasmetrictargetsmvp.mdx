## Description

You can now set periodic metric targets for goals, allowing you to define monthly target values and record actual progress against them. This update helps teams with quarterly or monthly reporting needs by providing period-by-period tracking and variance visualization, ensuring a consistent way to measure health across your organization. This feature is available for Strategy Collection customers. To set periodic metric targets: Navigate to a goal that has at least one metric attached.
