## Description

Save time and stay organized by setting a default view for your goals in the Atlassian Goals app. This change allows you to choose the most relevant view for your goals directory, ensuring you see the information you need as soon as you open the app. Create a saved view if you haven’t already.
	
		Pro tip: Try saving views by Team, Tag, or Status to keep things organized.
	
	
	Navigate to your preferred Saved view
	Click the More actions (⋯) menu
	Select Set as default view To remove a default v
