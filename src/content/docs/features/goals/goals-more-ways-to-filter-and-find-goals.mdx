## Description

Find and manage goals more efficiently in the Goals directory with four new filters. Filter by Score, Last updated, Target date, and Goal type to quickly identify risks, focus on upcoming deadlines, and remove outdated information from your view. More about this change To start using the filters: Go to the Goal directory.
	Locate the filter bar at the top of the directory.
	Choose from the new filter options, such as Last updated, Target date, Score, or Goal type, to refine your list.
