## Description

Site admins and app admins can now set the default access level for every new goal and project. This change allows organizations to choose between an open editing model or a more restricted viewing model by default, ensuring consistent governance across the app without requiring manual updates for each new item. To set the default access levels for goals: In the Goals app, select Settings, then select Goals settings.
