## Description

Trello now includes a source preview in the quick capture experience. This change allows you to see the original source of a captured item directly on the cardback, helping you maintain context and verify information without leaving your current view. For sources created from full pages or links, users will see a smartlink. To get started with this change: Open a work item that was created using quick capture.
