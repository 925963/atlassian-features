## Description

We've updated the visual layout of the Live Chat widget in Jira Service Management to improve the chat experience for your customers. When a human agent sends multiple consecutive messages, their avatar and name now appear below the last message in the group instead of above the first one. This refinement creates a cleaner, more deliberate layout that better reflects the intended design and visual hierarchy of the conversation.
