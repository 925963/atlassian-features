## Description

Rovo agents can now use tools to access and interact with information from Teams. This improvement allows your agents to provide more context-aware responses and perform actions related to your organization's structure and objectives within Atlassian apps. Go to Atlassian Studio.
	Select the Agents tab.
	Choose an existing agent or select Create agent.
	In the agent configuration, go to the Tools section.
	Select the tools for Teams to enable them for your agent.
