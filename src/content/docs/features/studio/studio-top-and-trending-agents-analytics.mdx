## Description

You can now access a consolidated analytics dashboard in Rovo Agent Studio to see how agents are being used across your organization. This update helps admins identify high-value agents to promote and low-usage agents to clean up, ensuring a high-quality agent catalog for your teams. Go to Rovo Agent Studio.
	Select the Insights dashboard.
	View usage metrics, including invocation counts and user engagement.
