## Description

We've updated our terminology in Atlassian Studio to better reflect how you automate your work. Automation rules are now called flows. This change provides a more intuitive way to describe the end-to-end processes you build to save time and stay organized. To view this change: Open Atlassian Studio and from the navigation on the left, select Automation.
	Look for the new Flows label (previously known as Rules).
	Select any existing flow to view or edit its triggers and actions.
