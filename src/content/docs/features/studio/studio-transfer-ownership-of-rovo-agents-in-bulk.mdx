## Description

Organizaiton admins and Studio admins can now manage Atlassian Rovo agents more efficiently by performing bulk actions. You can now select up to 100 agents to transfer their ownership to other users in a single step, saving time and simplifying agent management. To transfer ownership: Go to the Rovo agents landing page in Studio.
	Select the agents you want to manage using the checkboxes in the table.
