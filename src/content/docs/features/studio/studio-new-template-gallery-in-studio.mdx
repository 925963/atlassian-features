## Description

Save time and streamline your workflows with the new templates in Studio for automation flows and agents. This update provides a dedicated space to browse, configure, and enable templates, making it easier to implement powerful AI solutions across your work. Go to the app switcher and select Rovo Studio.
	Select Templates from the sidebar to browse available templates.
