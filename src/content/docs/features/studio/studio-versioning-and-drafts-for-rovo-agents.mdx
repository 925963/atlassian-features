## Description

Rovo agents now support versioning and drafts, allowing you to safely iterate on your agents without disrupting users. You can now prepare changes in a draft state, test them, and publish new versions only when they are ready. This update brings higher confidence to agent maintenance by ensuring that only one version is active at a time while you work on improvements in the background. To get started with this change: In your agent configuration, go to Details, then select Version History.
