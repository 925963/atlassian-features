## Description

Automations now includes a Project field value changed trigger and Goal status changed trigger, allowing you to automate workflows based on changes to project and goal fields. This update helps you automate workflows to help teams informed and documentation up to date as project or goal details evolve. To use the new trigger for Projects: In Automations, select Create flow.
