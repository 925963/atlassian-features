## Description

Save time when refining your app UI in Studio by using the new point-and-annotate feature. Instead of describing every change in chat, you can now select a specific part of the preview and provide targeted feedback for Rovo to update. Open your app preview in Studio.
	Select the Select element icon.
	Select the part of the UI you want to change.
	Enter your feedback in the annotation field and submit it to Rovo.
