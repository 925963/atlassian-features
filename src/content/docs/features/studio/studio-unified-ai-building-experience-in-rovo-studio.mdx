## Description

Rovo Studio is a unified building space where you can compose, customize, and control all your AI-powered workflows in one place. The latest version of Studio allows your team to create agentic automations and build custom apps without writing any code. More about what you can build in Studio If you’ve already been using Studio open beta, you don’t need to do anything. You’ve automatically been transitioned to the new version of Studio.
