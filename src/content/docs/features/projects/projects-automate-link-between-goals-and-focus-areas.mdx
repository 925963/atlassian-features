## Description

Automation for Focus now supports linking and unlinking Goals to/from Focus Areas using the existing actions Link work or goals to focus area and Unlink work or goals from focus area. This is an enhancement over existing provider support for Jira and Projects. To get started with this change In an automation rule, plug either of the following actions:
	
		Link work or goals to focus area
		Unlink work or goals from focus area
	
	
	In the action configuration:
	
		Set provider to Goals.
