## Description

In Talent, you can now use Include all when filtering on group fields such as Skills. This returns only those people who have every skill you selected. To use the Include all option: Filter a list by a group field such as Skills in Talent.
	Add more than one skill to the filter.
	Select Include all from the filter operator menu.
	Review the list of people who have every selected skill.
