## Description

Stay informed on your workforce data with customizable Talent sync notifications. You can now choose to receive alerts for successes, failures, or only when a sync recovers, ensuring you have the visibility needed to maintain data accuracy without the noise. To manage the notifications: Open the Talent app.
	Select your profile icon, then select Personal settings.
	Go to Notification preferences.
	In the Real-time notifications section, select the sync alert types that matter the most to you.
