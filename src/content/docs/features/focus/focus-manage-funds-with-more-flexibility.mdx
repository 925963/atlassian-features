## Description

Unlock financial insights in Focus by comparing benefits and costs with budgets, forecasts, and actuals. You can now enter values directly or import them from financial systems of record using comma-separated values (CSV) files or new public API endpoints. This visibility helps you make more informed investment decisions and reduces manual effort when syncing data. Open the Focus app from the app switcher.
