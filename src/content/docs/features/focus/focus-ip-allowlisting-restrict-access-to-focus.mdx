## Description

Organization admins can now use IP allowlisting to restrict access to Atlassian Focus. By specifying approved IP addresses or ranges in Atlassian Administration, you can ensure that only authorized users can access your Focus site and its data. This security measure applies to both the in-app experience and the external Public API. Go to Atlassian Administration at admin.atlassian.com.
	Select your organization if you have more than one.
	Select Security, then IP allowlists.
