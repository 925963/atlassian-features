## Description

You can now add an optional start date to focus areas in Atlassian Focus. This helps you communicate when work is planned to begin, providing clearer planning context and ensuring that capacity curves and mid-year plans accurately reflect future work. To add a start date: Open an existing focus area or create a new one.
	In the side panel, select the Start date field.
	Choose a date with day, month, or quarter precision.
	Select Save.
