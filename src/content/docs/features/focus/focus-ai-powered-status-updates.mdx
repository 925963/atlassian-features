## Description

Save time and keep stakeholders informed with AI-powered status updates for focus areas. Rovo now helps you draft concise, impactful updates by summarizing progress from sub-focus areas, goals, projects and Jira work items. Navigate to a Focus area.
	Select Updates.
	Select Draft updates to generate a draft.
	Review, edit, and select Post to share the update.
