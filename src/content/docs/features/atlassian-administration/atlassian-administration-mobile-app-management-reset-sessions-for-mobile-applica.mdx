## Description

Organization administrators can now use the “Reset Sessions” option to invalidate tokens that were issued to Mobile Applications for managed users. This Atlassian Administration feature safeguards your organization's data. To get started with this change: Go to Atlassian Administration at admin.atlassian.com.
	Select your organization if you have more than one.
	Select Security, then Device Security, and then Mobile app policies.
	Edit an existing mobile app policy and select Reset Sessions.
