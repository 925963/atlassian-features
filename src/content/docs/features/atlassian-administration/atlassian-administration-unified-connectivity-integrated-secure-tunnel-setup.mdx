## Description

Admins can now set up secure tunnels for Atlassian Rovo and Teamwork Graph connectors directly within the cloud connector setup wizard. This update to Atlassian Administration simplifies the connection between Data Center and cloud apps by removing the need to manually copy credentials or restart your Data Center instance.
