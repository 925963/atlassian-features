## Description

We've made improvements to how you handle access requests in Atlassian Administration. Request access emails are now more descriptive, making it easier for admins to understand and act on incoming requests. We've also made it easier to stay on top of pending requests directly from the user list. Log in to your Atlassian organization.
	Select Administration from the app switcher.
	Go to the Users section to view pending access requests.
