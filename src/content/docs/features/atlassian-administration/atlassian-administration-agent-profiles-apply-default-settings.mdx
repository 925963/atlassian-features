## Description

Organization admins can now apply default settings to agent profiles in Atlassian Administration. This change helps admins maintain consistency across their service teams and saves time when setting up new agents. Go to Atlassian Administration, then Rovo.
	Select Agents.
	Choose an agent to view their Agent Profile.
	From the dropdown menu at the top, select Add default access.
