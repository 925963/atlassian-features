## Description

Organization admins can now save time by removing up to 500 members from a group at once in Atlassian Administration. This update to the Group Members table allows admins to manage large groups more efficiently without the need to remove members individually. To remove multiple users in bulk: Go to Atlassian Administration. Select your organization if you have more than one.

	Open a group and go to the Members tab.
