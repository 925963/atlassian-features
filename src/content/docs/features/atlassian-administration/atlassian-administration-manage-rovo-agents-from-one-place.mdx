## Description

Organization admins can now manage and govern Rovo agents from a central location in Atlassian Administration. This update provides visibility into all agents across your organization and allows you to set default access policies for newly created agents. By centralizing these controls, you can ensure better security and compliance without searching across individual sites. To get started with this change: Log in to Atlassian Administration at admin.atlassian.com.
	Select Rovo, then select Agent
