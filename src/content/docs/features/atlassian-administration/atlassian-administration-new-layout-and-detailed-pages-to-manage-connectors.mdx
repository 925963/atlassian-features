## Description

Organization admins can now manage connectors in Atlassian Administration using a new table layout and dedicated detail pages. These updates help you monitor sync status and configuration details for your teamwork graph and search data. To view this change: Go to Atlassian Administration. Select your organization if you have more than one.
	From the left navigation, select Apps, then select Connectors.
	Select a connector from the list to view its new detail page.
