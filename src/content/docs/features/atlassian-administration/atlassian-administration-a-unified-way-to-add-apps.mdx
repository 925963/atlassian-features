## Description

We've updated the way you add apps in Atlassian Administration to provide a more consistent and streamlined experience. By unifying the add app flow, you'll now see a single, shared process for all apps, including a consolidated view for Terms of Service and security disclosures. Log in to admin.atlassian.com.
	Select your organization.
	Go to Apps → Atlassian apps and select Add app.
	Select the app and sites you would like to add and complete the setup
