## Description

Organization admins can now access a modernized User activity experience in Atlassian Administration. We’ve migrated these insights to our new analytics platform to provide more flexible filtering, finer and coarser time-range granularities, and a more consistent interface across Atlassian apps. To get started with this change: Log in to admin.atlassian.com.
	Select your organization.
	Go to Insights, then Analytics.
	Select the User activity tab to view the updated dashboards.
