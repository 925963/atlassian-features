## Description

Self-service signup for Rovo Dev has been removed from https://www.atlassian.com/ and Atlassian Administration. New customers must now contact sales to request the app, while existing customers retain all current access and billing functionality. New customers interested in Rovo Dev should visit the marketing or pricing pages on https://www.atlassian.com/ and select Contact sales.
