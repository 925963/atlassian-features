## Description

Organization admins can now create application links for Jira Cloud in Atlassian Administration using Cloud Connector. This new creation experience simplifies the setup process by removing the need to manually copy and paste credentials between Atlassian Cloud and Data Center apps. Go to Atlassian Administration.
	Select Settings, then Application links.
	Select Create link and follow the prompts to connect your Jira Cloud site to a Data Center instance using Cloud Connector.
