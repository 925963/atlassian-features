## Description

Atlassian Rovo now supports Model Context Protocol (MCP) v2. This update enables you to connect to every Atlassian app through a single, central interface. MCP v2 introduces dozens of new tools across Jira and Confluence while also adding Loom, Goals, Projects, Bitbucket, Focus, Teams and Talent support. To get started with this change, update from Atlassian Rovo MCP v1 to Atlassian Rovo MCP v2.
