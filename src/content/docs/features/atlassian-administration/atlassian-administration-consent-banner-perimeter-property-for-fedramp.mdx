## Description

Atlassian browser storage controls now includes a perimeter property for the consent banner. This update allows application developers to specify whether a consent banner applies to commercial or FedRAMP environments, ensuring that users receive the correct consent information based on their environment. Log in to your organization at admin.atlassian.com.
	Go to Security, then Consent banner.
	Select the Perimeter property to choose between commercial or FedRAMP.
