## Description

Organization admins can now filter audit logs in Atlassian Administration by authentication type and by actions performed on behalf of other users. This update helps admins more effectively monitor security events and troubleshoot access issues across their Atlassian organization. To filter audit logs: Go to Atlassian Administration. Select your organization if you have more than one.
	Go to Security, then Audit log.
	Use the new Authentication type and On behalf of filters to refine your search
