## Description

You can now reset a sandbox to its original, empty state. This allows you to quickly clear all data and configuration from your sandbox without having to delete and recreate it, saving time when starting new testing cycles or configuration changes. To get started with this change: Go to Atlassian Administration. Select your organization if you have more than one.
