## Description

Organization admins can now manage their connectors more efficiently in Atlassian Administration. We’ve revamped the connectors table and introduced new tools to help you filter connectors, see default apps, and other usability improvements. Go to admin.atlassian.com
	Select your organization if you have more than one.
	Select Connectors.
	Select a connector from the list to view its new tools table.
