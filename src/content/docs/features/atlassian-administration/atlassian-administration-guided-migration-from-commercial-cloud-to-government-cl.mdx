## Description

Eligible administrators can now use Atlassian Administration to copy data from existing Jira and Confluence sites in commercial cloud to Government Cloud with a guided migration flow. This first release supports full data copy only and provides step-by-step validation to reduce manual effort for government customers. To get started with this change: Log in to Atlassian Administration for Government Cloud.
