## Description

Organization admins can now view active users metrics with daily, weekly, and monthly granularities in Atlassian Administration. This update allows you to see more precise trends in user activity by automatically adjusting the chart's breakdown based on your selected date range. To get started with this change: Log in to admin.atlassian.com.
	Select your organization.
	Go to Insights, then Analytics.
	Select the User activity tab.
	Select a date range to see metrics at the requested granularity.
