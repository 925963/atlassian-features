## Description

Organization admins can now use data security policies to manage and protect content within Jira Product Discovery. To use data security policies for Jira Product Discovery: Go to Atlassian Administration at admin.atlassian.com.
	Select Security, Data protection, then Data security policy.
	Select an existing draft control or create a new one.
	When adding override, select your Jira Product Discovery spaces.
