## Description

Organization admins can register supported gallery MCP servers in Atlassian Administration using a customer-supplied API token. Access is protected by server-level role-based access control, so admins can control which people or groups can discover and use the server’s tools. To set up API token authentication for MCP servers: Go to Atlassian Administration. Select your organization if you have more than one.
	From the left sidebar, select Apps, then select Sites, and select your site.
