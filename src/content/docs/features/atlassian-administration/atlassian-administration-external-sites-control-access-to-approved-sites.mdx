## Description

Organization admins can now create an “External sites” policy in Atlassian Administration to limit which Atlassian sites users can access from their corporate network. This security feature helps prevent data exfiltration to unauthorized sites by ensuring users only interact with approved Atlassian apps and sites while on your network.
