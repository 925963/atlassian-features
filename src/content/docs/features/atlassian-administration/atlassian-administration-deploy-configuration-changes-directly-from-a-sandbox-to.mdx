## Description

Admins can now deploy configuration changes directly from a sandbox to another sandbox or to a production environment. This capability for Jira and Jira Service Management helps admins save time and reduce risk by eliminating the need to manually recreate tested changes, such as workflows and screens, in their production environment. Go to Atlassian Administration, then select Apps.
	Select Sandboxes, then find the Jira sandbox you want to deploy from.
	Select Actions, then select Create a deplo
