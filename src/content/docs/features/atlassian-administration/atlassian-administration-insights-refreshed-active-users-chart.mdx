## Description

The Active Users chart in Atlassian Administration is updated to provide more flexible reporting. Organization admins can now use date and app filters to explore active user trends across their organization more effectively. Go to admin.atlassian.com.
	Select your organization.
	Go to Overview.
	Interact with the Active Users chart using the new date and app filters.
