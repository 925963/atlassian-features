## Description

Guard Detect now resolves the account status of an actor on an alert against the specific site associated with that alert. If an alert is associated with multiple sites, it will display the actor's status from one of those sites. For org-scoped alerts that aren't tied to a specific site, it will continue to show the status from the Guard Detect site.
