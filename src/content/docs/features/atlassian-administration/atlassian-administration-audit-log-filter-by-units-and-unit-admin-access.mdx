## Description

Organization admins can now filter audit log events by units in Atlassian Administration. This change also allows unit admins to access the organization-level audit log to view events specific to the units they manage, providing more granular visibility into administrative actions. To get started with this change: Go to Security, then Audit log in Atlassian Administration.
	If you are an organization admin, select the Units filter to view events for specific units.
